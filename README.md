# 🖥️ Home Lab – Active Directory & IT Support

## 📌 Overview

This project documents the setup of a home lab environment using Proxmox to simulate a real-world IT support and systems administration environment.

The goal is to build hands-on experience with:

* Virtualisation
* Active Directory
* Windows Server administration
* Troubleshooting common helpdesk scenarios

---

## 🧱 Lab Architecture

* **Host:** HP EliteDesk 800 G4 Mini running Proxmox
* **Hypervisor:** Proxmox VE
* **Virtual Machines:**

  * Domain Controller (Windows Server)
  * Client Machine (Windows 10)

---

## ⚙️ Technologies Used

* Proxmox VE
* Windows Server 2022
* Windows 10
* Active Directory Domain Services (AD DS)
* DNS

---

## 🔧 What This Lab Demonstrates

* Setting up a virtualised environment
* Configuring static networking
* Installing and configuring Active Directory
* Creating users and organisational units
* Joining machines to a domain
* Troubleshooting login and network issues
